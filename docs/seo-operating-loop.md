# SEO operating loop

Review Search Console monthly after enough crawl and impression data is available. Export page/query pairs for Vietnamese searches, compare equal periods, and record the date and content change. Search position is an average and should be read with impressions, intent and page selection.

| Observation | Next action |
| --- | --- |
| Positions 1–10 | Keep the useful page accurate. Improve only where queries reveal a missing answer or user friction. |
| Positions 11–20 | Prioritize the existing URL: answer the query earlier, add a worked original example, clarify the title or description, and link from a relevant hub. |
| Positions 20–50 with rising impressions | Expand the relevant existing page to cover the observed need; add a focused practice block if appropriate. |
| No impressions after enough time | Check URL Inspection, sitemap inclusion, robots/noindex, canonical choice, crawlability, internal links, duplicate intent and actual usefulness. |

Before creating a new URL, identify the learner's distinct intent and check whether an existing URL should be improved. Merge or archive overlap with a valid redirect only when a useful destination exists. Never refresh `lastmod` for unchanged content.

For each publication: draft → deterministic quality gate → original-answer review → render/link/metadata tests → publish → verify public response and sitemap. Admin retains edit, preview, unpublish, noindex, archive and redirect controls. The gate detects structural risks, but it cannot prove copyright originality, factual accuracy or that every English distractor is unambiguous; those require an actual editorial check before publication.

Track meaningful acquisition: visits from organic search to a guide, practice starts, challenge starts and return learning. Avoid judging success by indexed URL count alone. Use [Search Console Performance](https://support.google.com/webmasters/answer/7576553?hl=en) and [URL Inspection](https://support.google.com/webmasters/answer/9012289?hl=en) for evidence.
